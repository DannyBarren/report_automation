Step-by-step (first-time setup)

1 Try automatic fix (no admin)

Click Fix dependencies now above, or close the browser and double-click run_demo.bat again.

Screenshot: browser showing this page with the blue “Fix dependencies now” button centered.

A Run as Administrator (recommended if auto fails)

  1. Close GenerSwift (Ctrl+C in the command window).
  2. In File Explorer, open your project folder (where run_demo.bat lives).
  3. Right-click run_demo.bat → Run as administrator.
  4. Approve the UAC prompt (“Do you want to allow this app to make changes?”).
  5. Wait for [OK] WeasyPrint is ready at step [3/4].
Screenshot: Windows Explorer context menu on run_demo.bat with “Run as administrator” highlighted.

B Portable setup (no administrator)

  1. Install 7-Zip (free).
  2. Run run_demo.bat normally — it extracts GTK into gtk3\runtime.
  3. Or click Fix dependencies now on this page.
Screenshot: Command window showing “Trying portable extraction (no administrator required)”.

2 Restart the app

After setup succeeds, stop and restart run_demo.bat so PATH and WEASYPRINT_DLL_DIRECTORIES apply to the Flask process.
