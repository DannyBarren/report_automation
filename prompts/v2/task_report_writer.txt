## field_values (mandatory)
- For **each** output section, set `field_values` to include **every** key listed in that section's `fields` array from the rules above.
- Use `field_specs` labels as guidance for tone and completeness.
- Map narration into: `condition_summary` (overall), `specific_findings` (facts), `recommendations` (actions), `severity` (enum).
- `severity` values: `no_issue`, `minor`, `moderate`, `major`, `safety_critical`, or `informational` — choose from narration; do not invent hazards.
- If the technician said "no issues" / "satisfactory", use `no_issue` or `minor` and state that explicitly in summaries and fields.
- Do not omit keys; do not add keys not in the template `fields` list for that section.
