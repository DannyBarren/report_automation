## Procedure
1. Detect every "{{ identification_phrase }}" (case-insensitive).
2. Map cue *k* → section *k* in template order; set `section_id`, `report_type`.
3. Narration window = same segment (after cue) through segment before next cue.
4. `image_timestamp_sec` = midpoint of cue segment (clamp to segment bounds).
5. Populate `context_before` / `context_after` from neighboring segments (include times if helpful).
6. Score `confidence` with rubric; set `noise_factors`, `inferred_terms`, `requires_site_verification`.
7. When a section has **no spoken cue** but a MARK tap exists at time *t*, anchor that section to
   the tap: use narration spoken near *t*, fold in the tap's typed note, and set
   `image_timestamp_sec` ≈ *t*. A typed note is reliable text (not ASR) — use it verbatim and raise
   confidence accordingly. Never invent findings beyond narration + notes.
